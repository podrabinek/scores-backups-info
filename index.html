PERSONAL BACKUP UTILITY

Scores backup

Scores backup is a private utility operated by the GitHub user podrabinek to store recovery copies of their own application databases and settings in their personal Google Drive.

How it works

The planned schedule creates one backup each day and retains the latest 30 successful copies. Archives are compressed without application-level encryption, as selected by the owner. Google Drive access is requested through OAuth using the drive.file scope.

The utility is intended for the owner's personal use. It is not a public backup service and does not accept registrations.
