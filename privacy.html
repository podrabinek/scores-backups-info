SCORES BACKUP

Privacy policy

Effective date: 17 October 2026.

Purpose and operator

Scores backup is operated by podrabinek for personal disaster recovery of the operator's own application. It is not a service for other users.

Data and Google Drive access

The utility uploads application database snapshots, runtime settings and recovery metadata to the operator's Google Drive. Settings may contain application credentials. It uses Google's drive.file permission to create and manage files and folders created by or specifically made available to the application. It does not request unrestricted access to the contents of the operator's Drive.

OAuth access and refresh tokens are stored in a restricted configuration file on the machine performing backups. These tokens are used only to authenticate backup, verification, retention and recovery operations.

Storage, use and sharing

Backups are transferred to Google Drive over HTTPS. The owner has chosen archives without additional application-level encryption. Archives should remain private in Drive. Data is used for backup verification and recovery, not advertising, sale or AI model training. The utility does not deliberately share archives with other users.

Google processes files stored in Drive under its own policies. This information website is hosted on GitHub Pages; GitHub may process request information under its own privacy policies. These static pages contain no analytics scripts or tracking cookies added by the operator.

Retention and deletion

The intended policy retains the latest 30 successful daily backups. Older copies are removed by the backup job. Temporary local snapshots may be created for upload and verification. The owner can delete backups in Google Drive, stop the backup schedule, and revoke the application's access in Google Account connections. Revoking access does not itself delete existing backup files.

Contact

For questions or deletion requests, contact the operator through the project's issue tracker. Do not post credentials or backup contents in public issues.
